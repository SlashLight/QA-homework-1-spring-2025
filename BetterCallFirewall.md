## Тестирование ленты
- При скроллинге ленты вниз новые посты загружаются автоматически;
- При продолжении скроллинга следующая загрузка постов не происходит;
> **[БАГ]** Некорректная пагинация
>
> Ожидаемый результат: При скроллинге ленты новые посты буду загружаться до тех пор, пока они не закончатся.
>
> Фактический результат: Работает только первая дозагрузка.

- После нажатия на аватар автора поста осуществляется переход на его страницу;
- После нажатие на имя автора поста не происходит переход на его страницу;
- После нажатия на аватар сообщества, которое опубликовало пост происходит переход на страницу сообщества;
- После нажатия на название сообщества, опубликовавшего пост, не происходит переход на страницу сообщества:
- При нажатии кнопки лайка меняется цвет кнопки и увеличивается счетчик;
- При нажатии кнопки комментария меняется цвет кнопки, появляется список комментариев и поле для ввода
- При заполнении ввода и нажатии зеленой кнопки под постом появляется новый комментарий и обновляется их счетчик
- Нажатие кнопки enter так же публикует комментарий;
- При нажатии "скрепки" появляется модальное окно с выбором файлов;
