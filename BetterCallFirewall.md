## Тестирование ленты
- При скроллинге ленты вниз новые посты загружаются автоматически; ✅
- При продолжении скроллинга следующая загрузка постов не происходит; ❌
> **[БАГ]** Некорректная пагинация
>
> Ожидаемый результат: При скроллинге ленты новые посты буду загружаться до тех пор, пока они не закончатся.
>
> Фактический результат: Работает только первая дозагрузка.
 ![Подгрузка](imgs/Подгрузка.png)

- После нажатия на аватар автора поста осуществляется переход на его страницу; ✅
- После нажатие на имя автора поста не происходит переход на его страницу; ❌
- После нажатия на аватар сообщества, которое опубликовало пост происходит переход на страницу сообщества; ✅
- После нажатия на название сообщества, опубликовавшего пост, не происходит переход на страницу сообщества; ❌
- При нажатии кнопки лайка меняется цвет кнопки и увеличивается счетчик; ✅
  ![Лайк](imgs/like.png)
  ![Лайк](imgs/likeSet.png)
- При нажатии кнопки комментария меняется цвет кнопки, появляется список комментариев и поле для ввода; ✅
![NoComment](imgs/noComment.png)
- При заполнении ввода и нажатии зеленой кнопки под постом появляется новый комментарий и обновляется их счетчик; ✅
![Comment](imgs/comment.png)
- Нажатие кнопки enter так же публикует комментарий; ✅
- При нажатии "скрепки" появляется модальное окно с выбором файлов; ✅ 
- При нажатии на кнопку "сначала старые" комментарии сортируются в порядке от старых к новым; ✅
![Сортировка](imgs/Сортировка_комменты.png)
- После нажатия на кнопку "Создать пост" открывается форма создания поста; ✅
![Create](imgs/Создать_лента.png)
![Форма](imgs/Форма.png)
- При нажатии "Прикрепить файлы" появляется модальное окно с выбором файлов; ✅ 
- При попытке опубликовать пустой пост появляется ошибка; ✅
![Пустой пост](imgs/Empty_post.png)
- При подгрузке файла отображается его имя; ✅
![Пост с файлом](imgs/Пост_с_файлом.png)
- При нажатии кнопки "опубликовать" пост создался и отображается в профиле; ✅
![Создался пост](imgs/Создался.png)
- При переходе в ленту после создания поста он отображается; ❌
> **[БАГ]** Некорректное отображение
>
> Ожидаемый результат: При создании поста он появляется в ленте
> 
> Фактический результат: Пост появляется только в профиле, в ленте - нет.
> ![Нет поста](imgs/Нет_нового.png)
- После редактирования поста - сохраняется новый текст и новые файлы; ✅
![Редактирование_форма](imgs/Редактировал_пост.png)
![Редактировал сохранение](imgs/Редактировал_сохр.png)
- При нажатии на кнопку "корзины" появляется модальное окно с подтверждением выбора; ✅
![Модальное окно](imgs/Модальное_окно_удалить.png)
- - При нажатии на кнопку "Удалить" пост удаляется; ✅
- - При нажатии на кнопку "Отмена" пост НЕ удаляется; ✅
- При создании поста с длинным текстом без пробелов текст не выходит за рамки; ✅
![Длинный текст](imgs/Длинный_текст.png)
