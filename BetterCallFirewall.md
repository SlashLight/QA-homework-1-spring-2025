## Тестирование ленты
- При скроллинге ленты вниз новые посты загружаются автоматически; ✅
- При продолжении скроллинга следующая загрузка постов не происходит; ❌
> **[БАГ]** Некорректная пагинация
>
> Ожидаемый результат: При скроллинге ленты новые посты буду загружаться до тех пор, пока они не закончатся.
>
> Фактический результат: Работает только первая дозагрузка.
 ![Подгрузка](imgs/Подгрузка.png)

- После нажатия на аватар автора поста осуществляется переход на его страницу; ✅
- После нажатие на имя автора поста не происходит переход на его страницу; ❌
- После нажатия на аватар сообщества, которое опубликовало пост происходит переход на страницу сообщества; ✅
- После нажатия на название сообщества, опубликовавшего пост, не происходит переход на страницу сообщества; ❌
- При нажатии кнопки лайка меняется цвет кнопки и увеличивается счетчик; ✅
  ![Лайк](imgs/like.png)
  ![Лайк](imgs/likeSet.png)
- При нажатии кнопки комментария меняется цвет кнопки, появляется список комментариев и поле для ввода; ✅
![NoComment](imgs/noComment.png)
- При заполнении ввода и нажатии зеленой кнопки под постом появляется новый комментарий и обновляется их счетчик; ✅
![Comment](imgs/comment.png)
- Нажатие кнопки enter так же публикует комментарий; ✅
- При нажатии "скрепки" появляется модальное окно с выбором файлов; ✅ 
- При нажатии на кнопку "сначала старые" комментарии сортируются в порядке от старых к новым;✅
![Сортировка](imgs/Сортировка_комменты.png)

## Тестирование своего профиля
- При нажатии на автарку в правом верхнем углу происходит переход на страницу профиля; ✅
- При нажатии кнопки "Профиль" на боковой панели происходит переход на страницу профиля; ✅
![Профиль](imgs/profile.png)
- На странице профиля при нажатии кнопки "Редактировать профиль" открывается форма редактирования профиля; ✅
![Форма](https://github.com/user-attachments/assets/b78e4013-3a2e-4977-a05f-a3096965c746)
- При изменении одного из полей "Имя", "Фамилия" и "Описание" и нажатии кнопки сохранить изменения сохраняются; ✅
- При изменении одного из полей "Имя", "Фамилия" и "Описание" и выходе изменения не применяются; ✅
- При введении в поля "Имя" или "Фамилия" текста с пробелами, появляется предупреждение; ✅
![Много пробелов](imgs/SpacesInName.png)
- При введении в поля "Имя", "Фамилия" текста длинной более 30 символов появляется предупреждение; ✅
![Имя слишком длинное](imgs/NameTooLong.png)
- При введении в поле "Описание" текста длинной более 60 символов появляется предупрждение; ✅
![Описание слишком длинное](imgs/DescTooLong.png)
- При выборе нажатии кнопки "Прикрпепить картинку" открывается модальное окно с выбором файла; ✅
- При выборе картинки она загружается и отображается в форме; ✅
![Предпросмотр](imgs/PicAttached.png)
- При выборе файла, не являющегося картинкой, и нажатии кнопки "Сохранить" появляется предупреждение о неправильном типе файла; ✅
![Неверный тип файла](imgs/ErrWrongType.png)
- При загрузке файла кнопка "Прикрпеить картинку" меняется на "Нажмите, чтобы отменить"; ✅
- При нажатии кнопки "Нажмите, чтобы отменить", прикрепленный файл удаляется; ✅
- При выборе картинки с размером выше 5 МБ и нажатии кнопки "Сохранить" появляется предупреждение о слишком большом размере файла; ✅
![Слишком большой размер](imgs/SizeTooBig.png)
- В форме "Сменить пароль" при введение текущего пароля в поле "Старый пароль", и не совпадающего с текущим пароля в поле "Новый пароль" и поле "Повторите пароль", пароль от аккаунта меняется на новый; ✅
- В форме "Сменить пароль" при введение неверного текущего пароля в поле "Старый пароль", и не совпадающего с текущим пароля в поле "Новый пароль" и поле "Повторите пароль", появляется предупреждение "Неверный пароль"; ✅
![Неверный пароль](imgs/WrongPass.png)
- В форме "Сменить пароль" при введение текущего пароля в поля "Старый пароль", "Новый пароль" и "Повторите пароль", появляется предупреждение "Неверный пароль" вместо "Пароли совпадают"; ❌
- В форме "Сменить пароль" при введение текущего пароля в поле "Старый пароль", и не совпадающего с текущим пароля в поле "Новый пароль" и пароля, отличного от введенного в поле "Новый пароль", в поле "Повторите пароль", появляется предупреждение "Пароли не совпадают"; ✅
![Разные пароли](imgs/DifferentPasswords.png)
- На странице профиля при нажатии кнопки "Удалить аккаунт" появляется модальное окно с кнопками "Отмена" и "Удалить"; ✅
- На странице профиля при нажатии кнопки "Удалить" аккаунт удаляется; ✅
- На странице профиля при нажатии кнопки "Отмена" происходит возвращение на страницу профиля; ✅
- На странице профиля при нажатии кнопки "Написать себе сообщение" открывается чат с самим собой; ✅
- На странице профиля при нажатии "Создать пост" открывается форма создания поста; ✅

## Тестирование друзей и их профилей
- При нажатии кнопки "Друзья" в боковой панели происходит переход к списку друзей; ✅
![Друзья](imgs/friends.png)
- При нажатии кнопки "Удалить из друзей" друг перемещается в "Подписчики"; ✅
- При нажатии кнопки "Подтвердить заявку в друзья" подписчик перемещается в список "Друзья"; ✅
- При нажатии кнопки "Добавить в друзья" пользователь перемещается в список "Подписки"; ✅
- Последний пользователь в списке не может быть добавлен в друзья; ❌
> **[БАГ]** Некорректное добавление в друзья
>
> Ожидаемый результат: Всем пользователям можно отправить заявку в друзья.
>
> Фактический результат: Последнему пользователю в списке нельзя отправить заявку в друзья.

- При нажатии кнопки "Написать сообщение" открывается чат с пользователем; ✅
- При нажатии на имя или аватар пользователя происходит переход на его страницу; ✅
![Профиль](imgs/UserProfile.png)
- На странице профиля при нажатии кнопки "Написать сообщение" на странице друзей открывается чат с пользователем; ✅
- При нажатии кнопки "Добавить в друзья" на странице пользователя, пользователю отправляется заявка в друзья и он переносится в список "Подписки" на странице "Друзья"; ✅
- При нажатии кнопки "Отменить заявку в друзья" на стрнанице пользователя, заявка отменяется и пользователь перемещается обратно в список всех пользователей на странице "Друзья"; ✅
- При нажатии кнопки "Принять заявку в друзья" на стрнанице пользователя из списка "Подписчики", заявка принимается и пользователь перемещается в список друзей на странице "Друзья"; ✅
- При нажатии кнопки "Удалить из друзей" на стрнанице пользователя из списка "Друзья", пользователь перемещается в список "Подписчики" на странице "Друзья"; ✅
